# HipoVisual Website

Готовый статический сайт.

## Запуск
Открой `index.html` в браузере.

## Настройка
1. В `index.html` замени ссылку `href="#"` у кнопки скачивания на ссылку на твой ZIP/лаунчер.
2. Замени блоки галереи на реальные изображения клиента.
3. При необходимости измени версию, поддерживаемую Minecraft и ссылки на Discord/Telegram.

## Публикация
Сайт можно разместить на GitHub Pages, Cloudflare Pages, Vercel или обычном веб-хостинге.


## Логотип
Используется логотип `images/hipovisual-logo.png`, предоставленный для сайта HipoVisual.
